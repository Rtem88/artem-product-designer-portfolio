# Artem Kabanchuk · Product Designer

Двомовне портфоліо українською та англійською: 8 кейсів, інформація про досвід, контакти й CV у PDF. Мова перемикається в хедері.

`index.html` самодостатній: стилі, скрипти, шрифти, зображення та CV вбудовані у файл. Для перегляду достатньо відкрити його у браузері. Сервер і встановлення залежностей не потрібні. Для хостингу завантажте також папку `cv`: сайт використовує окремі PDF для надійного завантаження. При відкритті локального HTML використовуються вбудовані копії. Посилання на оригінальні кейси та опубліковані проєкти відкривають зовнішні сайти.

## GitHub Pages

Завантажте вміст цієї папки в корінь репозиторію. Відкрийте **Settings → Pages → Build and deployment**, оберіть **Deploy from a branch**, гілку **main** і папку **/(root)**, потім **Save**. Після завершення публікації GitHub покаже адресу сайту. [Інструкція GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
